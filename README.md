# DiceGame

DiceGame — Ruby-игра про броски кубиков, бонусные комбинации и улучшения между раундами. Проект содержит игровую модель, симулятор и интерактивный цикл, где нужно набрать целевой счёт за ограниченное число бросков.

## ✨ Особенности
- Стартует с пулом случайных кубиков и пошаговыми раундами.
- Считает очки по числовым броскам, парам, тройкам, стритам и другим бонусам.
- Поддерживает специальные стикеры на кубиках: добавочные и мультипликативные.
- Позволяет улучшать пул кубиков между раундами.
- Содержит отдельный симулятор для многократного прогона и анализа средних результатов.

## 🚀 Быстрый старт
### Установка зависимостей
```bash
bundle install
```

### Запуск интерактивной консоли
```bash
bin/console
```

### Запуск игры из Ruby
```bash
ruby -r ./lib/dice_game -e "DiceGame::Game.new.run"
```

### Запуск тестов
```bash
rake spec
```

## 📁 Структура проекта
- `lib/dice_game.rb` — основной entrypoint и правила подсчёта очков.
- `lib/dice_game/game.rb` — игровой цикл, раунды и улучшения.
- `lib/dice_game/die.rb` — типы кубиков, их грани и механика улучшения.
- `lib/dice_game/sticker` — стикеры, влияющие на итоговый счёт.
- `lib/dice_game/simulator.rb` — симулятор многократных бросков.
- `spec` — тесты поведения игры.

## 🛠 Использование
### Интерактивная игра
```ruby
require 'dice_game'

game = DiceGame::Game.new
game.run
```

### Симулятор
```ruby
require 'dice_game'

stats = DiceGame::Simulator.new.run(rounds: 1000)
puts stats
```

### Что происходит при подсчёте
Базовый счёт строится из числовых значений выпавших граней, затем добавляются бонусы за комбинации и специальные эффекты кубиков/стикеров, а после этого применяются мультипликаторы.
